# 📄 R2 Live Streaming Migration TODO

## 🎯 Goal

Migrate the current monolithic streaming system (NodeMediaServer + FFmpeg + local filesystem) into a
**scalable cloud-transcoding architecture** using R2 + an external transcoder worker.

Currently the NestJS backend directly spawns FFmpeg processes, manages local HLS directories,
polls the filesystem, and uploads segments to R2 from inside the app. The goal is to delegate all
FFmpeg/transcoding/upload work to a separate `transcoder-worker` service, keeping the NestJS backend
only responsible for RTMP ingestion, DB state, and WebSocket events.


# 🧠 7. Playback URL System

## 📍 Function: `getStreamUrl()` — `media-server.service.ts` lines ~519–525

### Current (needs change)

```ts
getStreamUrl(streamKey: string): string {
  const session = this.activeSessions.get(streamKey);
  if (!session) return '';
  const publicUrl = process.env.PUBLIC_URL || process.env.HTTP_BASE_URL;
  return `${publicUrl}/media/live/${session.contentId}/master.m3u8`; // ← local HTTP, not R2
}
```

This currently returns a local media server URL (served by NodeMediaServer's HTTP), **not** the R2
public URL.

### ✅ CHANGE TO

```ts
getStreamUrl(contentId: string): string {
  const r2PublicUrl = process.env.R2_PUBLIC_BUCKET_URL;
  return `${r2PublicUrl}/live/${contentId}/master.m3u8`;
}
```

- Use `R2_PUBLIC_BUCKET_URL` (the Cloudflare public bucket URL, not `r2.cloudflarestorage.com`)
- Use `contentId` in the path, never `streamKey` (security)
- Format: `{R2_PUBLIC_BUCKET_URL}/live/{contentId}/master.m3u8`

# 🧠 9. New Component (CRITICAL)

## 📍 Create: `transcoder-worker/` (separate project / Docker container)

This is a **completely new standalone service** — not part of the NestJS app.
Recommended stack: Node.js + Express (or Fastify), Docker.

### API Endpoints

```
POST /transcoder/start   → Starts FFmpeg for a given RTMP stream
POST /transcoder/stop    → Kills the FFmpeg process for a given transcoderId
GET  /health             → Liveness check
```

### Responsibilities

1. Pull RTMP stream (`rtmp://media-server:1935/live/{streamKey}`)
2. Run FFmpeg with multi-bitrate HLS encoding (use existing args from `startFFmpegTranscoding()`)
3. Write `.ts` segments and `.m3u8` playlists
4. Upload each segment directly to R2 (using `@aws-sdk/client-s3`)
5. Generate thumbnail from the first segment → upload to `live/{contentId}/thumbnail.jpg`
6. Upload `EXT-X-ENDLIST` finalized manifest on stop
7. Retry failed R2 uploads
8. Callback / webhook to NestJS when:
   - `master.m3u8` is live on R2 (`POST /internal/stream/ready`)
   - thumbnail is ready (`POST /internal/stream/thumbnail`)

### Docker Compose

Add to `docker-compose.yml`:
```yaml
transcoder-worker:
  build: ./transcoder-worker
  environment:
    - R2_ACCESS_KEY_ID=...
    - R2_SECRET_ACCESS_KEY=...
    - R2_BUCKET=...
    - R2_PUBLIC_BUCKET_URL=...
    - RTMP_HOST=media-server
  depends_on:
    - rappio-server
```

# 🚀 Final Architecture

```
OBS / Streaming Client
  ↓ RTMP
NodeMediaServer (port 1935)  [stays in NestJS app]
  ↓ postPublish event
NestJS → TranscoderService.start()
  ↓ HTTP POST
Transcoder Worker (Docker)
  ├── FFmpeg pulls RTMP → encodes HLS
  ├── Uploads .ts segments directly to R2
  ├── Uploads .m3u8 playlists to R2
  ├── Generates thumbnail → uploads to R2
  └── Callbacks to NestJS (/internal/stream/ready, /thumbnail, /failed)
       ↓
NestJS → DB update + WebSocket broadcast
  ↓
R2 Storage → Cloudflare CDN → Viewers
```

# ⚡ Migration Summary

| Layer | Before | After |
|---|---|---|
| FFmpeg | Spawned inside NestJS (`child_process`) | Runs in `transcoder-worker` Docker container |
| HLS files | Stored locally in `media/live/{contentId}/` | Never touch NestJS disk |
| R2 upload | Filesystem watcher loop in `R2UploadService` | Worker uploads directly to R2 |
| Thumbnail | Filesystem polling for `000.ts` in NestJS | Worker generates + uploads; sends webhook |
| DB state | Set directly by `VideoService` | Set by NestJS on worker webhook callbacks |
| WS events | Emitted after local file ready | Emitted after worker webhook confirms |
| Playback URL | Local HTTP (`/media/live/...`) | R2 public URL (`{R2_PUBLIC_BUCKET_URL}/live/...`) |
